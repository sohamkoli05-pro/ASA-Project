# ASA Project — Statistical Analysis Using R

## 📌 Project Overview
This project focuses on statistical analysis using R programming. It uses a concrete dataset to perform data analysis and explore statistical patterns.

## 🎯 Objectives
- Analyze the concrete dataset using R.
- Apply statistical methods to the available data.
- Understand patterns and relationships within the dataset.
- Present the analysis results in a structured format.

## 🛠️ Technologies Used
- R Programming
- CSV Dataset
- Statistical Analysis

## 📂 Project Files
- `asa-project.R` — R source code.
- `concrete_data.csv` — Dataset used for analysis.
- `ASA Project Groups.pdf` — Project document.

## ▶️ How to Run
1. Install [R](https://www.r-project.org/).
2. Download or clone this repository.
3. Open `asa-project.R` in RStudio.
4. Ensure `concrete_data.csv` is in the working directory.
5. Run the script.

Run the R script to generate the analysis and outputs.
